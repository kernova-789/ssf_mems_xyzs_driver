# 型号描述与公共数据

当前只提供温振声 XYZS 型号的配置，没有增加 XYZ 型号选择或自动识别。
型号相关表项统一在 [modbus_table.h](modbus_table.h)，通用代码读取这些数据。

## 四个文件

| 文件 | 作用 |
| --- | --- |
| `modbus_table.h` | 帧、寄存器、块命令及型号参数的具体内容 |
| `modbus_table.c` | 生成唯一一份表，提供查询和校验函数，生成公共字段布局 |
| `sensor_data.h` | 驱动内部规范化结果结构，例如加速度 g×100、温度 ℃×100 |
| `sensor_fields.h` | 29 个公共字段的编号、缓存成员和单位类别，协议、IIO、自适应比较共用 |

`SSF_MEMS_DEFINE_MODBUS_TABLE` 只在 `modbus_table.c` 包含头文件前定义。
该文件因此编译表的定义；其他文件只看到 `extern` 声明，链接时引用同一份数据。
这让实际型号表继续集中在头文件，同时避免重复生成全局数组。

## 轴顺序

原始 XYZ 顺序与传感器手册一致。

## 量程与原始比例

当前型号参数：

```c
.raw_accel_scale_nano = 4788403,
```

它记录每个原始计数对应多少 m/s²，数值以十亿分之一为单位：
`4788403 / 1000000000 = 0.004788403 m/s²/count`。
IIO 原始通道的 scale 回调读取这个字段，原始 buffer 中仍保留传感器计数。
用户态按 `计数 × scale` 得到加速度。

当前值对应 ±16 g、16 位有符号计数，理论比例为
`16 × 9.80665 / 32768 ≈ 0.004788403 m/s²/count`。
这里保存的是已计算好的换算比例，没有另外保存一个 `range_g` 字段。
若未来型号手册确认 ±8 g 且计数定义相同，可改为 `2394202`；
它只改变用户态换算比例，不会发送命令修改传感器硬件量程。

## 其他型号参数

`ssf_mems_sensor_profile` 还集中维护：采样率文本和编码数量、波特率编码表、
默认工作波特率、默认采样率、定长采样率上限、特征使能掩码及位移。
IIO 可选值、采集初始化和参数校验都读取这些内容。
初始化会检查轴顺序必须是 0～2 的排列、比例非零且小于 1 m/s²/count，
并检查编码范围和表项唯一性，错误时报告表项名称。

寄存器 `.name` 是业务查询入口，地址可以随型号改变。
`.feature_field` 决定进入哪个规范化字段，`feature_multiplier / feature_divisor`
负责固件单位与内部单位之间的整数换算。例如温度从 ℃×10 统一到 ℃×100，
可设置分子为 10；公共缓存和 IIO 代码仍使用既定单位。

更换型号表只能覆盖已经描述出的差异。XYZ 的位移特征、可用通道、块范围、
私有包格式和 OTA 行为仍需逐项核对，不能承诺只换表就自动支持所有型号。
