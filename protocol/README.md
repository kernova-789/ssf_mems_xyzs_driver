# 协议模块

## 目录职责

| 位置 | 内容 |
| --- | --- |
| `protocol.c/.h` | 传感器业务接口：特征缓存、配置读写、帧分发、波特率匹配和修改 |
| `model/` | 完整寄存器表、型号参数、规范化数据结构和公共字段描述 |
| `modbus/` | RTU 组帧/解帧、请求等待与响应匹配、接收 FIFO 和解析窗口 |
| `transport/` | 串口发送、短写处理、线上耗时和帧间隔估算 |
| `raw/` | 定长批次触发、私有原始包解析、排空和通信恢复 |
| `firmware/` | 私有 OTA 包、应答、镜像校验和重启确认 |

常用入口：

- [型号配置说明](model/README.md)：轴顺序、量程比例、寄存器和单位映射。
- [modbus_table.h](model/modbus_table.h)：完整手册寄存器和型号参数。
- [定长采集说明](raw/RAW_CAPTURE.md)：批次格式、限制和 buffer 用法。
- [固件升级说明](firmware/OTA.md)：镜像要求、线上流程和用户命令。
- [IIO 属性说明](../iio/ATTRIBUTES.md)：全部用户态属性。

所有子目录头文件都以 `protocol/` 为包含根，例如
`#include "model/modbus_table.h"`、`#include "raw/raw_stream.h"`。
Kbuild 仍只把这些模块链接为一个 `ssf_mems.ko`。

## 型号表与寄存器访问

`model/modbus_table.h` 保留完整手册寄存器，包括未使用的连续采集寄存器。
表中同时定义帧格式、块命令和 `ssf_mems_sensor_profile`；
`model/modbus_table.c` 定义 `SSF_MEMS_DEFINE_MODBUS_TABLE` 后包含它，生成唯一一份表。
其他文件通过头文件中的 `extern` 声明共享数据。

业务层单寄存器操作先按稳定 `.name` 查表，再使用表中的地址、权限和格式。
名称区分大小写，必须唯一；空名称返回 `-EINVAL`，缺失名称返回 `-ENOENT`。
查询函数返回表项，`modbus/modbus_request.h` 提供直接按名称读写的接口：

```c
u16 value;
ret = ssf_mems_modbus_read_reg_by_name(serdev, "firmware_version", &value, 1000);
```

名称接口返回原始 16 位值，不拼接 U32、不换算单位。
`_locked` 版本要求调用者持有 `protocol.bus_lock`。
直接写 `"baudrate"` 只修改暂存值；完整改速应使用
`ssf_mems_protocol_set_baudrate()`，由它处理保存、重启和主机 UART 切换。

连续块仍批量读写。特征读取按显示地址寻找连续段，且要求线上地址也连续；
稀疏表自动分段，全部成功后才替换完整缓存。表顺序不会改变字段顺序。
删除某个特征表项后，剩余地址不重编号，缺失字段在成功快照中为零。
全部特征删除时不发送请求，缓存为全零；任一分段失败保留上次缓存。
完整手册表通常应保留；删除表项只是说明稀疏读取能力。

通用连续读写不跳过缺失寄存器：缺失返回 `-ENOENT`，权限不足返回 `-EACCES`，
不发送请求。固定十参数写入仍要求对应完整块；定长长度高低字要求显示地址和
线上地址都相邻，否则拒绝写入。

`ssf_reg_desc.feature_field` 指向公共字段编号，比例字段
`feature_multiplier / feature_divisor` 将固件值归一化为 `model/sensor_data.h` 的单位。
未填的比例各按 1 处理，先解释有无符号再做整数换算；越界返回 `-ERANGE`，
不覆盖缓存。字段布局、单位和未来型号限制见 [型号配置说明](model/README.md)。

初始化在访问型号数组前校验编码范围、默认值、使能掩码、轴排列、原始比例，
以及寄存器名称/地址/字段唯一性、权限和块描述。无效表返回 `-EINVAL` 并记录出错名称。
允许稀疏表和缺少可选业务寄存器，缺失业务在调用时报告。

## 接收与请求

普通帧路径：串口字节 → 接收 FIFO/工作项 → 长度和 CRC 校验 →
注册的 `ssf_mems_protocol_handle_frame()` → 请求层认领 → 帧编解码器解码。
未认领帧直接丢弃，不更新结果或缓存，也不按长度猜测寄存器起点。
帧数据位于接收器自有窗口，指针只在同步回调期间有效，调用者不能保存。
回调上下文须存活到接收清理完成，回调不能等待同一工作项处理新的应答。

接收窗口最多 256 字节，保留所有可能帧头；各帧头独立计时，预算为
最长 RTU 帧传输时间加 100 ms，按实际速率和校验格式估算。
后续字节不能延长旧帧头的寿命，伪长帧不会占满固定候选槽而挡住合法帧。
合法内层帧不清掉未完成的外层帧，已经完成的候选不会重复交付。
解析、过期清理和 flush 共用 `parse_lock`。

发送前等待至少 3.5 字符时间、最少 2 ms 的空闲，并清理旧 FIFO/半帧。
请求超时、部分发送或等待被信号打断后，下一请求先等待隔离窗口：
`max(1000 ms, 上次请求响应超时)`，从失败结束计时。
隔离后空闲检测最多再等待 1000 ms；持续噪声返回 `-ETIMEDOUT`。
常量见 `modbus/modbus_request.h`，等待可被卸载或信号打断。

RTU 读取应答没有地址或事务编号，因此迟到时间超出隔离窗口时，软件无法区分
同形旧应答与新应答。实机仍需验证最大延迟并调整等待预算。
发送预算与帧间隔由 `transport/serial_transport` 统一估算。

## 初始化与生命周期

core 设置 `data->serdev` 后先初始化协议，再初始化请求、接收和采集。
协议初始化设置从站地址 1、默认 9600、无校验，并解析设备树属性：

- `sange-cbm,slave-id`：1～247；可读但越界会失败。
- `current-speed`：初次匹配提示，缺失、不可读或不支持时保留默认速率。
- `sange-cbm,parity`：`none`、`odd` 或 `even`；可读但非法会失败。

属性缺失/不可读会记录默认值并继续。串口打开后统一配置主机速率、校验位和关闭流控；
控制器拒绝非默认启动速率时回退默认。`host_baudrate` 此后记录实际控制器速率，
`baudrate` 保存匹配到的固件编码。驱动不读取、扫描或修改传感器校验寄存器。
probe 不发送传感器命令；IIO 注册后启动采集线程，等待 1 秒再匹配和采集。
工作目标由型号表决定，成功的用户波特率和采样率设置由采集模块保存为重连目标。

`write_wakeup` 转发至 `serdev_device_write_wakeup()`，允许同步发送处理部分写入。
卸载先停止 OTA 并关闭请求，唤醒在途等待，再停止采集、注销 IIO、释放接收资源。
初始化仅用于尚未投入使用的状态，不能直接重复初始化运行中的模块。
锁顺序为采集锁 → 总线锁 → 请求锁；接收回调不取采集锁或总线锁。
不能持请求锁执行 flush，否则等待接收回调可能互相阻塞。

## 波特率与独占通信

读取波特率先在当前 UART 速率读 `"baudrate"`；仅超时才扫描各个不同的型号编码速率。
成功应答所在速率才是当前通信速率，寄存器可能只是尚未保存的暂存值。
成功保留匹配速率；全部超时或出现其他错误恢复入口速率。
默认码与显式 9600 不重复扫描，匹配过程只读，不保存或重启。

写同值波特率会先实读确认：主机速率、已知通信速率和寄存器值都一致时只读返回。
其余情况在旧速率写波特率、写保存命令，再静默等待 8000 ms、切换 UART 并读回验证。
保存地址和编码来自型号表，当前为 40102 和 40110=1。
验证最多 8 次，仅超时重试，不重复保存；常量位于 `protocol.h`。
保存应答丢失也保留静默期，返回错误；已保存而验证失败时不盲目恢复旧速率。
等待持总线锁，避免其他请求插入，默认时长仍需按实机最长启动时间确认。

`protocol.mode` 区分普通通信、原始启动、原始收流、恢复未确认和 OTA。
请求层在原始/恢复/OTA 状态拒绝普通请求并返回 `-EAGAIN`；
若升级结果不确定而暂停通信，上层 IIO 传感器配置接口返回 `-EBUSY`。
恢复只允许专用只读确认；关停期间的恢复读不会重新开放普通请求。
定长原始采集与 Modbus 共用工作速率，不提供连续采集专用启停、请求或解析流程。
原始私有数据由 `raw/` 解析，普通寄存器读取拒绝私有启动响应。

## 日志与验证

特征读取完整成功后可调用 `ssf_mems_protocol_log_features()`，内部使用 `pr_debug`，
默认不逐轮打印。它输出定点数的 g、mm/s 和 dB，无内核浮点运算；
`store_features()` 本身只更新缓存，不输出特征日志。
支持 dynamic debug 的内核可按 `protocol/protocol.c` 开启相应调试信息。

运行 `python3 tests/protocol/run_tests.py` 验证独立编译、公共头文件、模块依赖、
型号表校验、17 种表变体、响应匹配、抗噪接收、定长批次和波特率流程。
模拟测试不能代替真实 UART、RS485、电源和固件时序验证。
